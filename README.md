# 📡 LitPulse（研究脉搏）

一个**会主动找你**的论文追新 Agent：登记你的研究课题后，它定时扫描 arXiv 最新论文，
用大模型判断每篇与你课题的相关性并说明关系，生成"本周值得读"的 Markdown 周报；
同时用本地长期记忆**去重**、并记录你标记的"已读 / 有用"文献。

> 设计动机：常见的文献管理工具是"被动工具箱"——你不打开它，它不会为你做任何事。
> LitPulse 反过来做**主动推送 + 长期课题记忆**的研究副驾驶：你登记一次课题，
> 它每周主动替你盯 arXiv，还会记住你读过的每一篇和你的研究立场。

## ✨ 特性
- 📚 **我的文库**：上传的 PDF 永久保存在本机 `library/`，随时重新打开；自动识别标题/作者/日期/页数（含脏标题清洗：自动剥离被误并进标题的作者名单/单位上标，老数据启动时自愈）；**精读笔记随论文一起保存**，可在文库里直接查看/下载
- ✏️ **研究课题可在网页修改**：追新周报页直接改课题与 arXiv 关键词（存 `data/topic.json`，命令行/定时任务也读同一份，无需改代码）
- 🔗 **粘贴链接/DOI/标题直接入库**：粘 arXiv 链接或编号、DOI、或论文标题，自动联网（arXiv + CrossRef，均免费免 key）补全**标题/作者/期刊会议/卷期页/DOI/文献类型/摘要**；arXiv 开放论文会顺带下载 PDF，拿不到开放 PDF 的正式论文先存为带完整信息和原文链接的条目
- 🌐 **老 PDF 一键联网补全**：已上传的论文卡片上可按标题/DOI 联网回填期刊会议、卷期页、DOI、类型、摘要；支持「仅填空缺」或「以在线为准覆盖」，全程不碰本地 PDF、精读笔记和标注
- 🏷 **标签 + 📁 文件夹组织**：一篇可贴多个标签、归入多个文件夹（集合）；顶部可按关键词/标签/文件夹联合筛选
- 📥 **BibTeX 导出**：单篇导出或把当前筛选结果整批导出为 `.bib`；自动按文献类型生成 `@article/@inproceedings/@incollection/@book/@phdthesis/@misc`，citation key 自动取「一作姓+年份+标题首词」并去重，特殊字符自动 LaTeX 转义（可直接进论文 `.bib`）
- 📖 **在线阅读 + 原文标注自动存回**：内置 pdf.js，支持翻页/缩放/搜索/打印；用自带 Highlight 高亮、Text 文字、Draw 手绘标注后**自动烘焙进 PDF 并存回文库**，下次打开标注还在（停笔约 1 秒静默保存，无需手动下载）
- 🔎 arXiv 免费 API，无需学术库 key
- 🤖 LLM 逐篇相关性打分（0–10）+ 一句话"和你课题的关系"，自动过滤关键词噪声
- 🧠 本地长期记忆 `data/seen.json`：论文去重、状态标记（new/read/useful/skip）
- 📝 生成可收藏的 Markdown 周报
- 🔑 配置与密钥分离（`.env`），也可在网页侧边栏直接填 Key；兼容任意 OpenAI 接口的模型
- 💻 纯 Python 标准库 + openai，电脑可跑；双击即用，可挂定时任务推送到手机

## 📖 使用指南（网页五标签详解）

打开 `http://localhost:8501` 后，顶部五个标签页就是完整工作流，按顺序正好是「找文献 → 读文献 → 管文献 → 追新」的完整闭环：

### 1. 精读论文 —— 上传即入库，一篇吃透
- **上传**：把论文 PDF 拖进上传框。上传后自动：入库「我的文库」→ 解析全文 → 建立检索索引（首次约 1~2 分钟，之后秒开）。
- **精读笔记**：点【生成精读笔记】，得到总结 / 大纲 / 核心论点 / 术语表，每个论断都带页码出处；笔记随论文保存在文库，随时回看、可下载 `.md`。
- **带出处问答**：底部提问框输入问题（例：“它的实验方法是什么？”），回答**只依据检索到的原文片段**，并给出页码；点页码旁「📄 定位」可直接跳回 PDF 原句高亮。中文提问英文论文也行——检索零命中时自动切换全文通读模式，依然带页码。
- **联网补全信息**：论文信息卡上，若标题/作者/期刊等不全，会出现【联网补全信息】按钮（arXiv + CrossRef 免费接口，无需模型 Key），点一下即可回填，字段卡上会显示“联网补全”来源标记。
- **思考题模式**：点【生成思考题】出 5 道开放题；逐题用自己的话作答，导师按「答到的点 / 理解偏差 / 参考要点 / 再想一想」四段点评——不直接给答案，引导你想通为止。

### 2. 多篇对比 —— N 篇成一张表，看清异同
- 一次多选 2~6 个 PDF，自动抽取「问题 / 方法 / 数据集 / 毇标 / 结果 / 结论」生成对比矩阵；某个单元格没有的信息会明写“资料中未明确提及”，**绝不编造**。
- 每个单元格带页码，可点击跳回原文；可下载对比表 Markdown。
- 【整库综述】在矩阵基础上再综合：演进脉络 / 共识 / 分歧 / 选型建议，论断带 `[n:pX]` 多篇页码引用。

### 3. 追新周报 —— 登记课题，每周自动找新论文
- **首次使用**：在「研究课题」输入框填一句话课题（例：检索增强生成（RAG）：如何让大模型基于外部知识库准确回答、减少幻觉），再填 2~4 个英文 arXiv 关键词（例：retrieval, augmented, generation），点【保存】后【立即扫描并生成周报】解锁。
- 每次扫描：拉取 arXiv 最新论文 → 长期记忆去重（看过的不再重复推荐）→ AI 按你课题打分（0–10）+ 一句话说明关系 → 生成 Markdown 周报，只有 ≥7 分才进「本周值得读」。
- 课题随时可改：直接改输入框内容再点保存即可，下次扫描生效。
- **主动推送**：配好定时任务（见下方 ⏰ 章节，时间由你定，示例为每周一早 9 点），到点自动扫描并生成周报——这是 LitPulse 和“被动工具箱”最大的不同。

### 4. 追新库 —— 你的长期阅读记忆
- 扫描过的每篇论文都在这里：统计卡片（累计/待读/已读/有用）、立场分布、按状态/立场筛选。
- 每张论文卡可标记：**待读/已读/有用/忽略** 四种阅读状态；更关键的足**研究立场**五选一（支持我的课题 / 质疑 / 方法可借鉴 / 数据可复用 / 仅相关）。
- AI 每周先做立场初判（标 🤖），你确认后锁定（标 👤）；立场跨周累积，周报末尾会生成「立场地图」——以你的课题为中心，看证据如何站队。

### 5. 我的文库 —— 你的个人文献库
- **存放**：上传过的 PDF 永久保存在本机 `library/`，不丢；元数据（标题/作者/日期/页数/期刊/DOI）一张信息卡。
- **组织**：任意标签 + 文件夹双重归类；顶部按关键词/标签/文件夹联合筛选。
- **在线阅读**：点【在线阅读】用内置 pdf.js 直接看，支持高亮/文字/手绘标注，**停笔约 1 秒自动存回**，下次打开还在。
- **BibTeX 导出**：单篇或按当前筛选整批导出 `.bib`，citation key 自动生成，可直接进论文。
- **粘贴导入**：没有 PDF 也能建条目——粘 arXiv 链接/编号、DOI 或论文标题，自动联网补全信息；arXiv 开放论文还会顺带把 PDF 下载回来。

## ⚡ 一键启动（普通用户，无需敲命令）

**Windows（推荐，两步）**：
1. 解压 LitPulse.zip 得到 `litpulse` 文件夹，打开它；
2. 双击 **`启动LitPulse.bat`**。

**Mac**：双击 **`启动LitPulse.command`**（首次若提示无权限，在终端对该文件执行一次 `chmod +x`）。

> 需要先装好 **Python 3.10+**（Windows 安装时务必勾选 ☑ Add python.exe to PATH）。
> 首次启动会自动：创建独立运行环境 → 安装依赖 → 补装 pdf.js → 打开浏览器
> `http://localhost:8501`。首次约等几分钟，之后每次秒开。

**浏览器打开后，3 步完成首次配置：**
1. 在**左侧边栏【模型设置】**选服务商（如 DeepSeek），粘贴你的 API Key，点【保存配置】——
   立即生效，**不需要手改任何文件**。
   没有 Key？到 https://platform.deepseek.com 注册并充值（最低 10 元）后即可使用。
2. 到【追新周报】填写研究课题并保存（详见使用指南）。
3. 开始使用五个标签：📄 精读论文 / 📊 多篇对比 / 📡 追新周报 / 🧠 追新库 / 📚 我的文库（详见上方「📖 使用指南」）。

**手机访问**：双击 **`启动LitPulse-手机访问.bat`**（Windows），手机连同一 WiFi，
用窗口里的 `Network URL` 打开。

> 若解压后中文文件名乱码，可用英文名备用启动器：`START-LitPulse.bat`（Windows）、
> `START-LitPulse-LAN.bat`（手机访问）、`START-LitPulse.command`（Mac）。

## 📚 单篇论文精读（reader.py）
```bash
# 导入 PDF 并生成中文精读笔记（总结/大纲/核心论点/术语表/思考题），导出到 notes/
python3 reader.py notes 论文.pdf

# 基于原文的带【页码出处】问答（先检索相关片段，再让模型只依据片段作答）
python3 reader.py ask 论文.pdf "这篇论文的方法是什么？"

# 加 --save 可把问答追加保存到 notes/*_问答记录.md
python3 reader.py ask 论文.pdf "它的实验结论是什么？" --save

# 生成 5 道思考题（含评分要点与建议回看页码）；交互式作答与导师点评见网页
python3 reader.py quiz 论文.pdf
```
- PDF 逐页解析、切块（带页码、带重叠），索引缓存到 `data/chunks/`，二次提问免解析
- **混合检索（BM25 + 语义向量）**：
  - 默认零依赖 BM25（关键词精确匹配）；
  - 安装可选依赖后自动启用本地多语言向量模型 `sentence-transformers`
    （免费离线，首次自动从 hf-mirror 下载约 120MB），升级为
    **混合检索**：BM25 与向量各自归一化后按 0.4/0.6 加权融合，
    对"中文问英文原文""换个说法提问"等无语素重叠的情况显著更准；
  - 向量缓存到 `data/vectors/*.npz`；未装库或构建失败会自动降级 BM25，不影响使用。
- 长文档自动"分段摘要再汇总"
- 防幻觉：提示词强制"只依据检索片段作答 + 标注页码 + 资料没有就明说"
- **思考题导师互动**（网页端）：出题 → 看评分要点/参考答案 → 你作答后，导师按
  「✅答到的点 / ⚠️理解偏差 / 💡参考要点 / 🔎再想一想」四段点评，用引导式问题启发，不直接灌答案
- 依赖：`pip install pypdf`（可选升级：`pdfplumber`）

## 📊 多篇对比矩阵 + 整库综述（compare.py）
```bash
# 给 N 篇同主题论文，终端打印「问题/方法/数据集/指标/结果/结论」对比表
python3 compare.py 论文A.pdf 论文B.pdf 论文C.pdf
python3 compare.py A.pdf B.pdf --save      # 同时导出 reports/compare_*.md

# map-reduce 整库综述：对比之后再综合写出「演进脉络/共识/分歧/选型建议」
python3 compare.py A.pdf B.pdf --review --save   # 额外导出 reports/review_*.md
```
- **完全复用单篇精读的检索**：对每篇按 6 个维度各发一句定向 query，走 reader 的
  BM25+向量**混合检索**取最相关片段（而非整篇塞给模型），合并去重后**每篇仅一次模型调用**
  抽取结构化 JSON，再汇成一张字段×论文的对比表。
- **可溯源、不编造**：每个单元格的页码只能取自片段标注，资料没写就显示"资料中未明确提及"；
  网页端单元格里的 `📖p页码` 可点击，用内置 pdf.js 直接翻到该页并高亮原句。
- 某一篇抽取出错不会拖垮其它论文，会在该行单独标注原因。
- **整库综述（map-reduce 的 reduce）**：map 已把每篇压成统一证据卡，reduce 再用
  **一次模型调用**综合写出「🛣️方法演进脉络 / 🤝共识 / ⚔️分歧 / 🧭选型建议」。
  每个关键论断内联标注 `[n:pX]`（n=第几篇、X=该篇页码），网页端可点击直接跳 pdf.js 原文；
  内置**引用合法性自检**，凡页码超出该篇实际抽取范围会标记警告，防止模型编造出处。
- 网页端在「📊 多篇对比」标签：一次多选 2~6 个 PDF，带进度条，可下载对比表/综述 Markdown。

## 📱 手机端 / 电脑端网页（app.py）
```bash
pip install -r requirements.txt   # 额外安装 streamlit
bash setup_pdfjs.sh               # 可选：下载 pdf.js（启用"点击页码跳回原文"）
streamlit run app.py
```
- 电脑浏览器会自动打开 `http://localhost:8501`
- **手机使用**：电脑和手机连同一个 WiFi，用启动时提示的 **Network URL**
  （形如 `http://你电脑的局域网IP:8501`）在手机浏览器打开即可，界面自适应单列。
- 网页含五个页面：📄 精读论文（上传即入库→在线阅读→笔记→带出处问答）、📊 多篇对比（N 篇成对比表+整库综述）、📡 追新周报（一键扫描）、🧠 追新库（立场/标记）、📚 我的文库（持久文献、在线阅读、标注）。
- **引用点击跳回原文**：问答/思考题答案下的「📄 第X页·定位」按钮，用内置
  pdf.js 在新标签打开 PDF，自动翻到该页并用 `#search=` 高亮原文关键词。
  原理：应用内标准库 HTTP 守护服务（默认 8502 端口）只白名单托管 `static/`、`uploads/`、`library/`，
  不暴露代码/.env/data；同 WiFi 的手机可直接访问。
- 数据与命令行版完全共用（`data/ notes/ reports/`）。
- 若要在任何网络下都能访问，可部署到服务器（注意加访问鉴权，勿裸奔公网）。

# 📚 标记文献（喂养你的长期记忆）
```bash
python3 mark.py list                       # 查看记忆库
python3 mark.py 2610.29933 useful          # 标记为有用
python3 mark.py 2610.29933 read            # 标记为已读

# 研究立场：确认/修正 AI 的判断（确认后 AI 以后不再覆盖）
python3 mark.py 2610.29933 stance support  # 支持我的课题
python3 mark.py 2610.29933 stance oppose   # 质疑/反例
python3 mark.py 2610.29933 stance method   # 方法可借鉴
python3 mark.py 2610.29933 stance data     # 数据集/代码可复用
python3 mark.py stance method              # 列出所有"方法可借鉴"的论文
```
立场五类：`support 支持 / oppose 质疑 / method 方法 / data 数据 / related 仅相关`。
AI 每周先做初判（周报里标 🤖），你确认后置为 👤 并锁定；这些立场跨周累积成
周报末尾的「🗺️ 立场地图」，以你的课题为中心看证据如何站队。

## ⏰ 让它"主动"起来
- 仓库自带 `push_weekly.sh`：跑完追新会输出周报全文、并在末尾给出
  `MEDIA:/绝对路径/周报.md`，便于定时系统把周报和文件一起推到手机。
- **macOS/Linux**：用 cron 每周一早上运行，例如
  `0 9 * * 1 /path/to/litpulse/push_weekly.sh`
- **Windows**：用"任务计划程序"定时运行 `weekly_pulse.py`
